# 实现状态

## 已实现的本地原型

- FastAPI API、独立 Worker 与 Scheduler，SQLite 本地持久化及显式迁移。
- 默认单个本地工作区，无 API Token 或登录；内部资源仍按工作区归属处理。
- JSON 分析输入、CSV 资产导入预览；币种、时区、有限小数、重复资产与缺失价格校验。
- 外部资金流调整收益与已估值资产占比；确定性 Decimal 计算，展示来源、时间与覆盖。
- 持久任务、幂等键冲突检测、取消、租约与旧 Worker 结果隔离；崩溃最多恢复三次。
- 有序任务事件、事务内站内提醒，以及配置租户的 Webhook 投递队列。
- Webhook 签名、固定已验证公网目标、指数重试、失败队列和投递状态。
- 固定快照周期任务，错过多个周期只补跑一次，暂停停止关联未完成任务。
- 对话优先的同源工作台，持久会话、流式文字、工具调用记录和关联任务卡。
- Pi Agent Core + pi-ai 运行循环，DeepSeek/Anthropic 模型适配，调用本地财务工具。
- 官方 MCP SDK 的管理员配置 stdio tools，按租户白名单及运行租约检查。
- 单会话互斥、请求去重、超时、工具调用预算；停止回复关闭本轮 Pi 进程。
- 真实默认 Linux 图形桌面、noVNC 用户操作、Pi 图像工具；内部有界脚本工具。
- Binance/OKX 官方 CLI 只读适配、按需固定版本安装、租户凭证引用配置。

## 当前边界

这是对话与工具能力已接入的开发原型，不是完整金融助手。已有按需公共行情查询；交易所私有账户查询未配置真实凭证，也没有周期账户同步、自主研究、Telegram 以外的消息渠道、入站分析回调、外部异步分析执行、服务器 Runner、生产身份系统和 PostgreSQL 部署。

周期任务仍使用用户确认的固定快照，不能用于实时价格或风险监控。Agent Worker 具有租约心跳、有界模型执行和失败恢复；外部执行仍需独立适配与验收。

Webhook 配置修改需重启进程。部署前需更换开发凭证存储、增加用量与请求限制、用户身份管理、审计保留和服务监控。健康接口只检查数据库，不证明全部任务健康。
