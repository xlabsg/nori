# 内部命令工具

用户界面以 [Linux 图形桌面](desktop.md) 为主，不提供独立终端入口。`terminal_exec` 保留供 Agent 在同一图形容器的 `/workspace` 编写和运行脚本。

每条命令为非交互 bash，最长 30 秒，同一对话同时运行一个命令。文件跨命令共享，`cd` 和环境变量不跨调用保留。输出最多 65,536 字符，Agent 返回最多 12,000 字符并标记截断。超时或输出超预算会停止整个容器（包括桌面），避免残留后台子进程。

SQLite 保存命令状态与输出；相同 request_id 的已结束命令不重复执行，内容不一致拒绝。运行中的重复请求不能重放。服务异常退出的 running 记录在 120 秒后，由下一次请求标记 interrupted 并停止旧容器；不自动重试原命令。API 断线不是可靠的取消确认，应查询历史；长任务恢复仍需后续持久执行队列。

环境的构建、权限、网络和生命周期见桌面说明。仅测试创建的容器会在测试结束后自动删除；本地原型尚无全局容器回收器。
