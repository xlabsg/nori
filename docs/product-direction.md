# Nori 产品方向：对齐 ChatGPT dots 的持续工作助手

更新：2026-10-01。本文记录当前定位建议与现有能力边界；不承诺未实现的功能。

## 核心定位

**在对话里交代工作，连接自己的工具，让助手在后台执行并带回结果。**

主要产品参考为 ChatGPT dots。官方说明强调持续负责工作、自己的电脑和浏览器、
连接工具、在对话之间跟进，并在需要时向用户带回结果或请求判断。
来源：[Meet dots](https://learn.chatgpt.com/docs/dots)、
[Tasks and memory](https://learn.chatgpt.com/docs/dots/tasks-and-memory)。

本项目沿这个方向构建可自行部署的开源实现。当前是本地部署原型，运行主机必须在线。
对标的是工作方式；使用独立的 Pi 运行时、任务系统和桌面实现，不推断或复刻 dots 内部架构。

## 首版应该让人记住什么

首版面向希望把重复的信息检查交给助手、并控制本地运行环境的个人用户。
先聚焦“邮件 + 日程”的持续工作闭环：

- 用户提出每天汇总邮件和日程，助手保存明确的时间、时区和范围。
- 后台读取已连接的数据源，整理结果，用户回到提醒收件箱查看。
- 用户指定变化监控或会前提醒，重要更新通过可选 Telegram 带回。

这些是当前已有工具与任务模式能承载的场景，不在用户连接账号时自动创建。
文档中的示例不代表已给某个用户启用任务。

Linux 桌面提供浏览器与软件操作环境，MCP 提供外部工具，调度和通知负责持续执行与交付。
这些能力共同服务上面的工作流程；介绍产品时先呈现用户交代的工作和收到的结果。

## Finance 在什么位置

目前 Finance 的实现主要是交易所只读查询、快照导入与确定性分析。
尚未形成完整的实时持仓、资产关注和长期投资研究闭环，不能称为成熟的金融专业助手。
因此 Finance / crypto 保留为可选工具与示例方向，不作为当前主定位。
产品名称已确定为 **Nori**。对外文档和界面采用新品牌；本地目录、Python 模块、
数据库位置和服务标识暂沿用 `finance-agent`，兼容已有安装。

## 对齐的体验与实际差距

| 维度 | 本项目当前状态 | 对齐方向中的缺口 |
| --- | --- | --- |
| 对话入口 | 流式对话、工具调用、历史记录 | 尚无通用跨对话记忆和持续任务笔记 |
| 持续执行 | 一次性、间隔、每日任务；服务在线时运行 | 尚无自主规划长期目标、自主暂停/唤醒与续作 |
| 工具与数据 | Google 只读、管理员配置的 stdio MCP、可选交易所工具 | Connector 范围有限；通用远程 OAuth 工具未实现 |
| 电脑与浏览器 | 按需本地 Docker Linux 桌面与 Browser/Computer Use | 非独立托管云电脑，非永久桌面工作区 |
| 结果与沟通 | 持久结果、站内提醒、Telegram 出站通知、Webhook | 无双向 Telegram/Slack/Teams 对话连续性 |
| 主动性 | 用户明确指定的监控与提醒 | 无自主主动研究，不自动给用户添加任务 |

对 dots 的能力描述依据上述官方文档；本项目一栏是当前实现审查。
“对齐方向”不代表这些缺口已安排实现或即将交付。

## 下一次产品验证

建议先验证一个完整场景：用户只需一次交代“每天早上汇总邮件与日程”，之后能连续收到
有实际内容的结果，修改时间或暂停任务，并理解读取失败与没有新内容的区别。

演示应展示对话交代、保存的任务、后台运行和结果交付。当前 README 静态截图使用虚构
邮件与日程，只展示界面；不以预写对话冒充真实模型调用或任务执行录像。

长期目标跟进、记忆和更多数据源属于后续讨论。用户已暂缓的任务意图识别、Connector
扩展接口、执行诊断三个实现项，本次继续保持暂缓。
