Your Linux desktop is ready

This is Chromium running inside a real Linux container. Browse the web, use desktop apps, and share the workspace with Nori.

Use the Applications menu and desktop shortcuts to open the file manager, Calc spreadsheets, Writer documents, the text editor and PDF reader. Python includes pandas, NumPy, Matplotlib and SciPy; Git, curl and jq are also installed.

Working files are stored in /workspace. Temporary files are cleared when the environment stops.
