# Changelog

## 0.1.0 — local alpha

- Chat-first workspace with Pi Agent Core, streaming replies and stdio MCP tools.
- Persistent analysis and agent tasks, scheduling, notifications and signed webhooks.
- Read-only Google mail/calendar and Binance/OKX query integrations.
- Optional on-demand Debian/XFCE desktop with browser and computer-use tools.
- Telegram outbound reminders and local background service support.
- Apache-2.0 license, bilingual documentation and automated checks.

This is an initial alpha, not a production hosting release.
